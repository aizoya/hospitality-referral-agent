# Hospitality Referral Agent

**Turn referrals into follow-ups.**

Hospitality Referral Agent is an AI-powered workflow for food businesses that helps organize referral leads, score priority, explain why each lead matters, and draft owner-approved follow-ups.

## Problem

Food businesses often receive referrals through texts, calls, email, word of mouth, and community partners. Those leads can easily get lost during busy operations.

## Solution

The Hospitality Referral Agent helps:

- Organize referral leads
- Score lead priority
- Explain the reason behind each score
- Recommend the next action
- Draft follow-up messages
- Keep a human in control before anything is sent

## Safety

- No auto-sending
- Human approval required
- Sample data only during the hackathon
- No private data scraping
